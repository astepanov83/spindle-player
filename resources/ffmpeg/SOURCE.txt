Source code for ffmpeg and ffprobe
==================================

Spindle ships two programs it did not write: ffmpeg and ffprobe, in this
folder. They are John Van Sickle's static build of FFmpeg 7.0.2 for Linux x64
(https://johnvansickle.com/ffmpeg/), as republished by the ffmpeg-static
project (https://github.com/eugeneware/ffmpeg-static, release b6.1.1).
Spindle runs them unmodified, as separate programs.

They are licensed under the GNU General Public License version 3
(LICENSE.txt in this folder). Spindle itself is under the MIT license.
README.txt in this folder is the build's own notes, with the versions of the
libraries built into it.


Where to get the source
-----------------------

The source we have for these two programs is one archive,

    ffmpeg-7.0.2-linux-x64-source.tar

published in the same place as each Spindle release that ships them, and
kept there for as long as that release is offered:

    <SOURCE ARCHIVE URL: put the release download link here before publishing>

It holds the FFmpeg 7.0.2 source, the source of each library linked into the
build whose version is known, the build's configure line, and SOURCES.txt,
which says where each file came from, how sure we are that it is what was
built, and its sha256.


What is not in it
-----------------

This is not the full Corresponding Source the GPL describes, because not all
of it is public. John Van Sickle's build scripts are not published, and the
build does not record the versions of a few libraries linked into it: GMP,
Nettle, libtasn1, Fontconfig, libogg, and the GNU C Library (linked
statically). For libtheora and libvidstab the version is known but not the
exact commit; the archive holds the most likely one and says so. Some
libraries may have been built with Debian's patches, which the archive
does not have. SOURCES.txt lists each case.


Written offer
-------------

For at least three years after we last distribute a Spindle release that
includes these programs, we will give anyone who has a copy of them the
source listed in SOURCES.txt, at no charge, by download. If we find the
missing parts, we will add them.

To ask for it, open an issue at
https://github.com/astepanov83/spindle-player/issues
and say which Spindle version you have.
